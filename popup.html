Project History v4.3.0
v4.3.0 - Sync, Feedback & Backup
  • ⚙️ Settings now sync automatically across all Chrome devices with the same Google account.
  • 💾 Dual-Storage system: settings are saved in both sync and local — never lost after reload.
  • ⬇️ Export / ⬆️ Import settings as a JSON backup file (Settings tab).
  • 💬 New Feedback tab with direct link to the feedback form.
  • 🚫 Block button repositioned inline next to channel names (not on thumbnails) for clarity.
  • All 5 languages updated with new translations.
v4.2.0 - Channel Blocking
  • New dedicated "Blocked" tab for complete channel management.
  • 🚫 Block button next to channel names on all YouTube pages.
  • Channels can also be blocked manually by typing the handle in the popup.
  • Blocked channels are hidden immediately everywhere on YouTube.
  • Sidebar toggle bug fixes (Explore, Shorts, Legal) fully resolved.
  • All 5 languages updated with new blocked channels translations.
v4.1.3 - UI Polish & Sorting
  • Dynamic version displays from manifest.
  • Added sorting options for blocked channels (Alphabetical, Chronological, Reverse Chronological).
  • Up-to-date changelog integration.
v4.1.2 - Channel Blocking
  • Introduced complete channel blocking functionality.
  • New "Blocked" tab to manage completely hidden channels.
  • Inline block button on YouTube video cards.
v4.1.1 - Stability Patch
  • Fixed regressions in settings persistence.
  • Restored Icons in Emoji Theme Selector.
  • Improved loading sequence for smoother UI.
v4.1.0 - Manual Language Switch
  • Added manual language selector in Settings tab.
  • Custom i18n engine allows overriding browser locale.
  • Instant UI refresh on language change.
v4.0.0 - Global Localization (i18n)
  • Full support for EN, DE, TR, ES, FR.
  • Dynamic Translation engine (data-i18n).
  • Translated Store Metadata in manifest.
v3.3.3 - Layout Support
  • Added support for YouTube's new "yt-lockup" layout.
  • Fixed "Ends With" bug by bypassing hidden duration metadata.
  • Implemented URL-decoding for Turkish handles (@ÇokGüz...).
v3.3 - Precision Filters
  • Added match types: Contains, Starts With, Ends With, Exactly.
  • Implemented Turkish Locale Support (tr-TR) for dotless-i.
  • Added Hide/Show mode toggle for keyword rules.
v3.2 - Title Keywords
  • Initial Title Keyword Filtering engine.
  • Case-insensitive substring matching.
v3.1 - Personalization
  • New Settings Tab for Customization.
  • Dynamic Accent Color engine (Color Picker + Hex).
  • Emoji Theme Preset selector (Classic, Privacy, Check).
v3.0 - Design Revolution
  • Complete UI Redesign (Modern Red/Dark Gloss Theme).
  • Standardized 500x600px Zero-Scroll layout.
  • Polished animations and tab transitions.
v2.x - Detox Features
  • Sidepanel Detox (Hide Shorts, Subs, Explore).
  • Auto-Expand Subscriptions logic.
  • Channel Duration Rules (Min/Max).
v1.0 - Initial Release
  • Basic Video Filtering engine.
  • Manifest V3 migration.
